# Eternal Threads — Shopify theme

Built on [Dawn](https://github.com/Shopify/dawn) 16.1.1 by Shopify, with the Eternal Threads brand layer:

- `assets/et-brand.css` — brand styles (colours, type, square corners, custom sections)
- `sections/et-*.liquid` — custom sections: banner, category tiles, shop the look, image + text, trust row, journal feature, photo pair, full-width photo, article
- `snippets/et-image.liquid`, `snippets/et-product-extras.liquid` — image fallback and product page extras (fit note, size charts, returns)
- `templates/` — home, collection (shop-all, shirts, pants, accessories), product, blog, article and `article.intro`
- `assets/et-*.jpg`, `assets/et-logo-*.svg` — bundled campaign photos and wordmark

Connect this repo in Shopify: Online Store → Themes → Add theme → Connect from GitHub.
